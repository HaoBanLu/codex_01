# 泡泡爪宠物洗护项目说明

## 项目概述

本项目是一个面向宠物洗护门店的静态单页官网，主要用于展示“泡泡爪宠物洗护”的品牌定位、服务项目、洗护流程、价格套餐与预约入口。页面采用中文内容，适合宠物店、小型门店活动页或本地生活服务落地页使用。

项目当前由一个 `index.html` 页面和多张门店/洗护主题图片组成，无需后端服务即可直接在浏览器中运行。

## 核心功能

- **品牌首页展示**：顶部固定导航展示品牌名称、页面锚点和“立即预约”入口。
- **首屏图片轮播**：使用多张洗护场景图作为背景轮播，配合圆点按钮手动切换。
- **动态营业数据**：根据当天日期生成“今日已洗护”“平均护理分钟”“今日可约时段”等展示数字，让页面更有运营感。
- **服务项目介绍**：展示温和沐浴、深层梳理、低噪吹干、细节护理等洗护服务卖点。
- **洗护流程说明**：通过步骤化内容介绍入店评估、安抚清洁、吹干修整、护理反馈的完整服务流程。
- **价格套餐展示**：按小型犬/猫、中型宠物、长毛精护展示不同起步价和包含项目。
- **预约表单入口**：提供宠物昵称、宠物类型、联系电话、体型和期望到店时间等输入项，便于后续接入真实预约系统。
- **响应式布局**：页面适配桌面端、平板和手机端，移动端会自动调整导航、卡片和表单布局。

## 本地预览

由于项目是纯静态页面，可以直接双击 `index.html` 在浏览器中打开，也可以使用本地静态服务器预览：

```bash
python3 -m http.server 8000
```

启动后访问：

```text
http://localhost:8000
```

## 后续可扩展方向

- 将预约表单接入后端接口或第三方表单服务。
- 增加门店地址、地图导航、客户评价和作品案例模块。
- 为图片资源增加压缩和懒加载策略，提升移动端加载速度。
- 拆分 CSS 与 JavaScript 为独立文件，便于多人维护和版本管理。
- 增加真实营业数据来源，替换当前基于日期生成的演示数据。
